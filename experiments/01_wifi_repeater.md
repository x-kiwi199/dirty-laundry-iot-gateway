## Experiment 01 – Wi-Fi Repeater

### Tooling
Wi-Fi network scanning application inSSIDer by Metageek used on laptop. Mobile phone Wi-Fi scanning by settings. 

### Setup
- High-power router in repeater mode (both wired/wireless parent ap connection)
- Multiple fixed channels tested (2.4 GHz / 5 GHz)
- Channel width tuning
- Tweaking router Wi-Fi config
- Physical repositioning (relocation)
- Orientation

### Result
❌ Failed

### Findings
- Severe attenuation
- Unreliable discovery
- Inconsistent RSSI
- No stable link at appliance location

### Lesson Learned
Wi-Fi is not a viable transport to the cellar. At best we reach the doorways of the room.

### Note
- Data is not committed due to privacy protection.
