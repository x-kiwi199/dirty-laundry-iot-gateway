# Context

## Summary

The household uses Miele washing machine and dryer appliances that support smart
features via the Miele cloud. These features include status reporting, finish
notifications, and energy/water usage feedback (EcoFeedback).

At the appliance location, no fixed internet connection is available, and extending
the home network proved impractical. The only viable connectivity option is cellular
(5G/LTE).

## Motivation

The initial motivation was twofold:
1. Enable the smart features that were part of the appliance purchase decision
2. Explore and understand how modern appliances communicate with vendor clouds

## Mission

We want to reconnect the appliances back to the internet. Quite difficult task in an
environment without fixed internet connectivity, while keeping the solution reliable,
cost-aware, battery-powered, and usable by all household members.

Beyond achieving basic connectivity, the project aims to balance technical
curiosity with real-world constraints such as power availability, data cost,
maintenance effort, and family acceptance. The resulting system should function
as quiet household infrastructure—always available, rarely noticed, and
requiring minimal interaction—rather than as an ongoing technical experiment.
