# Observations (by daily usage)

## Data Usage

- CallYaSIM from Vodafone - Only data used for 3 cents per MB. Total about 14,55€/485MB/73d/(40 washing cycles + 33 drying cycles).  
- Every cycle is about a few MBs, definetly less than 15MB. Nominal range is about 1MB-7MB, by my crude eye balling measurement.

## Appliance Behaviour

- Smart features work and that reliably.
- Even after appliance startup it can reach the Miele servers and stream cycle data and reports. I was wrong on my early deductions.
- Within the first 15mins of the cycle the adjustement notification is pushed, e.g. reduced cycle duration due to lesser payload.

## Tablet Behaviour

- Battery and tablet lasts up to 3 days, unfortunatetly no charging logic for the old tablet possible.
