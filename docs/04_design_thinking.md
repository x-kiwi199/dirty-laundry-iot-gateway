# Design Thinking

The project began with a classic engineering mindset:
build a dedicated gateway using modular components.

Through experimentation, it became clear that:
- Power management dominates the design
- LTE reliability matters more than protocol visibility
- Household acceptance is a hard requirement, not a soft one

The design focus shifted from:
"How do I build the most elegant gateway?"
to:
"What solution works every day without attention?"

This shift led to accepting consumer devices as valid infrastructure
components rather than inferior compromises.
